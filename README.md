# Eshtaol Eyuel — Portfolio

A responsive Next.js portfolio starter built with React, TypeScript, and Tailwind CSS v4.

## 1. Open it in VS Code

1. Extract `eshtaol-portfolio.zip`.
2. Open VS Code.
3. Choose **File → Open Folder**.
4. Select the extracted `eshtaol-portfolio` folder.

## 2. Install the packages

Open the VS Code terminal (**Terminal → New Terminal**) and run:

```bash
npm install
```

## 3. Start the website

```bash
npm run dev
```

Open this address in your browser:

```text
http://localhost:3000
```

Keep the terminal running while you view the site. Press `Ctrl + C` in the terminal to stop it.

## 4. Check the project

```bash
npm run lint
npm run build
```

## 5. Personalize before publishing

- Check every biography and project description for accuracy.
- Add verified repository links to the project cards when you have them.
- Add a real domain to the metadata in `app/layout.tsx` if you later deploy the site.
- Add a real social preview image if you create one.

## Notes

- The theme toggle remembers the selected theme in the browser.
- The mobile navigation has an accessible open/close button.
- This ZIP contains the source project, not a deployed website.
- `node_modules` is intentionally not included. `npm install` creates it on your computer.
